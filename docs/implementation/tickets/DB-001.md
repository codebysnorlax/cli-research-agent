## Behavior
- Database file created at `data/email.sqlite` on first run
- WAL mode enabled for concurrent read performance
- Foreign keys enforced
- `CREATE TABLE IF NOT EXISTS` + `CREATE INDEX IF NOT EXISTS` = idempotent
